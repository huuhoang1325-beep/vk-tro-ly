# Trợ lý Vạn Kiếp Tu Tiên

Công cụ chạy ngay trong trang game Vạn Kiếp Tu Tiên (qua một dấu trang), dùng chính code hiện tại của game để:

- xếp kinh mạch tối ưu (ảnh + bảng so sánh), tìm ô tắc nên mở;
- tính tỉ lệ đột phá theo từng phương án đan / đốt thọ;
- mô phỏng khảo hạch tông môn, nhiệm vụ, đánh thử quái;
- đo giá trị đồ trong Tàng Kinh Các.

Mở `index.html` (trang GitHub Pages của repo) để chép mã dấu trang và xem hướng dẫn.

Tool chỉ tính toán, không tự bấm gì trong game.
